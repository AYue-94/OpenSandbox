组件遥测配置

为 Go 运行时组件配置并禁用 OTLP 指标。

Go 组件（包括 execd、egress 与 ingress）共用一个 OTLP metrics exporter。请在组件进程环境中设置这些变量。在 lifecycle server 上或沙箱创建请求中设置它们，不会自动配置另一容器（例如 egress sidecar）。关于由 server 管理的 egress 端点，参见 egress 可观测性。

导出端点与禁用指标

exporter 使用 HTTP/protobuf，且 OTEL_EXPORTER_OTLP_METRICS_ENDPOINT 优先于 OTEL_EXPORTER_OTLP_ENDPOINT。请使用 collector 的 HTTP receiver（通常为端口 4318）。gRPC 导出，以及通过 OTEL_EXPORTER_OTLP_PROTOCOL 切换传输，均未实现。

为兼容性，当两个端点均未设置时，execd、egress 与 ingress 也可使用 HOST_IP:4318，或从 /etc/hostinfo 读取的节点 IP。在共享遥测配置中设置了 DisableEndpointFallback 的组件会跳过该回退。因此，仅清空端点变量并不总能禁用指标。

设置以下任一标准开关即可阻止指标导出，包括显式端点与节点 IP 回退：

OTEL_SDK_DISABLED=true
# Or disable metrics only:
OTEL_METRICS_EXPORTER=none

取值不区分大小写。其他取值不会改变现有导出配置；此处 OTEL_METRICS_EXPORTER 也不会选择其他 exporter。这些开关不会禁用原生应用日志，也不会禁用 execd 本地的 /metrics 与 /metrics/watch API。它们还会抑制 egress sidecar 的自动 collector allow 规则，包括在有效策略被重建时。运维人员显式提供的 allow 规则仍然有效。

聚合时效性（temporality）

设置 OTEL_EXPORTER_OTLP_METRICS_TEMPORALITY_PREFERENCE 以选择 exporter 的标准聚合行为：

取值 Counter 与 Histogram ObservableCounter UpDownCounter 与 ObservableUpDownCounter
cumulative Cumulative Cumulative Cumulative
delta Delta Delta Cumulative
lowmemory Delta Cumulative Cumulative
未设置、为空或仅空白 Delta Cumulative Cumulative

取值不区分大小写。无效的非空取值会使用上游 exporter 的 cumulative 默认值，并产生其配置警告。Gauge 仍为瞬时测量。未设置时的行为会保留各组件既有的聚合语义。

类 Prometheus 后端期望 cumulative 的 counter 与 histogram。请在组件环境中设置 OTEL_EXPORTER_OTLP_METRICS_TEMPORALITY_PREFERENCE=cumulative，或在摄入 delta 指标时配置 Collector 的 deltatocumulative processor。请在组件启动前选定该设置；这些环境变量不会热重载。
